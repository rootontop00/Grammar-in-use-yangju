구글 시트 만들기
아래 형식으로 시트를 만드세요. 첫 행은 헤더입니다.

2
시트 공개 설정
파일 → 공유 → "링크가 있는 모든 사용자" → 뷰어로 설정
3
index.html 파일에서 SHEET_ID 수정
이 파일 상단의 SHEET_ID 값을 구글 시트 URL에서 복사하세요.
시트 URL 예시:
https://docs.google.com/spreadsheets/d/여기가_SHEET_ID/edit

index.html 15번째 줄:
const SHEET_ID = '여기에_붙여넣기';
4
오디오 시트 열 (audio_url)
같은 장면의 오디오는 첫 번째 행에만 입력. 나머지는 비워도 됩니다.
구글 드라이브 링크는 공유 설정을 "뷰어" 이상으로 해야 합니다.
